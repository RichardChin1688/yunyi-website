**设计原则**：品牌展示与知识长文分层。面向访客的页面以图为主、字为辅；供 AI 与搜索引擎引用的品牌事实、养生常识与问答集中收在 `/brand/`，只挂底部导航，不打扰顶部结构与整体观感。

## 二、双语实现

| 项 | 做法 |
|----|------|
| URL | 中文 `https://yunyi.homes/xxx/`；英文 `https://yunyi.homes/en/xxx/` |
| `hreflang` | 每页三条互指：`zh-CN` / `en` / `x-default`（指向中文页） |
| `canonical` | 各语言页自指，避免被判重复内容 |
| `<html lang>` | `zh-CN` / `en` |
| 语言切换 | 顶栏胶囊按钮，指向对应语言绝对 URL |
| 内容策略 | 英文为对应撰写非逐句直译；事实、口径、合规边界与中文完全对齐 |


## 五、内容口径（全站页脚均有声明）

| 口径 | 说明 |
|------|------|
| 零功效宣称 | 不写止痛 / 消肿 / 改善 / 缓解 / 有效等表述 |
| 零疾病名 | 不出现任何病名 |
| 零绝对化用语 | 不写「最」「第一」「唯一」「顶级」「100%」 |
| 不涉线下场所 | 不写诊所、门店、到店 |
| 不涉价格成本 | 只写零售价 |
| 不涉佣金规则 | 只写「以书面协议为准」 |
| 创始人表述 | 照创始人自述口径上屏，标注「以其自述为准」，不作第三方背书 |
| 隐私保护 | 创始人及其家人的个人生活信息一律零出现 |

> 产品为日常养生用品，非药品、非医疗用途。全部内容为品牌与健康知识信息，不构成医疗建议。
